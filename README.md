# Azonosító

## Program célja
Ennek a programnak a célja a belépő emberek és járművek adatai naplózása, ezután ezeknek keresése.

## Menüpontok
A program indulásakor 3 menüpont közül választhatunk számok bevitelével: 1. Személy belépés | 2. Jármű belépés | 3. keresés

Ha '1'-et írunk, akkor azzal egy belépő személynek az adatait tudjuk felvinni. Megadható adatok:
  - név
  - személy igazolvány száma

Ha '2'-t írunk, azzal egy belépő járműnek az adatait tudjuk felvinni. Megadható adatok:
  - jármű márkája
  - jármű típusa
  - jármű színe
  - jármű rendszáma

### Mindkettőnél automatikusan tárolja a naplózás idejét.
Ha '3'-at írunk, azzal keresni tudunk a már elmentett adatok között. Lépései:
  - Megadjuk a keresett szót
  - Megadjuk, mi alapján szeretnénk keresni: 1. Személy neve alapján | 2. Jármű rendszáma alapján | 3. Jármű típusa alapáján | 4. Jermű márkája alapján
  - A program kiírja azokat az elmentett belépéseket, ahol az adott adat megegyezik a keresett szóval

## Mire használható?
A program egy portaszolgálati beléptető rendszerként használható. Használatával a portás rögzítheti a belépő személyek és járművek adatait és a belépés idejét. Az elmentett adatok között kéősbb pedig név, rendszám, típus és márka alapján kereshet, így egyszerűen vissza lehet keresni, hogy ki lépett be az épület területére.
